## Minimum manual test checklist

- [ ] Game appears in the library after selecting its file.
- [ ] Game starts and reaches its first interactive screen.
- [ ] On-screen D-pad and buttons respond.
- [ ] Bluetooth/game controller responds when paired.
- [ ] Graphics remain stable through a short play session.
- [ ] Audio starts and remains synchronized.
- [ ] Pause, resume, and exit work without losing the library.
- [ ] No repeated crashes or native runtime loading errors.

A blank test table is not a compatibility claim. Update it only after testing the named title on the named device.
