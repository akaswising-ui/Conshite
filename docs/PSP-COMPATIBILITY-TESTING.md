# Conshite PSP compatibility test plan

Conshite uses the pinned PPSSPP Android engine. Compatibility is recorded per title and device; a successful APK build is not proof that every PSP game runs.

| Area | Test | Result |
|---|---|---|
| File access | Import an ISO through the document picker | Not tested |
| File access | Import a CSO through the document picker | Not tested |
| Launch | Start a selected title from the Conshite library | Not tested |
| CPU | Reach the first interactive screen | Not tested |
| Graphics | Confirm visible output without major corruption | Not tested |
| Audio | Confirm audio starts and remains synchronized | Not tested |
| Touch | Test on-screen D-pad and action buttons | Not tested |
| Controller | Test a paired Android-compatible Bluetooth controller | Not tested |
| Lifecycle | Pause, resume, and return to GameHub | Not tested |
| Save data | Save, relaunch, and check the title save | Not tested |
| Stability | Play for 15 minutes and record freezes or overheating warnings | Not tested |

Test only homebrew titles or game images you are legally entitled to use. Do not store game images in this repository. Add a result only after running the named title on the named device.
